## Reporting a Vulnerability

If you discover a security vulnerability in this Rainmeter skin (such as path traversal in dynamic file writes, unsanitized PowerShell argument execution in `pick_color.ps1`, or unsafe Lua file I/O operations), please report it responsibly:

1. **Do not create a public issue**: Please do not open public GitHub issues or discussions for sensitive security bugs.
2. **Contact Privately**: Send details via GitHub Security Advisory (preferred) or email the maintainer via privacy-safe developer contact: `211186833+RONALD-REX-7@users.noreply.github.com`.
3. **Include Details**: Provide a description of the issue, affected script or INI meter, reproduction steps, and potential execution risk.

Reports will be reviewed and addressed promptly.
